# AniQuiz｜多人線上動漫猜謎

這是一個使用 Node.js、Express 和 Socket.IO 製作的多人即時動漫猜謎網站。

## 功能
- 建立 4 位數房間代碼，朋友可從不同裝置加入
- 最多 12 位玩家同房
- 每場隨機抽出 10 題動漫題目
- 每題 20 秒、答對 +10 分
- 即時顯示作答進度、答案解析和排行榜
- 房主可開始、切換下一題、重新開始
- 手機與電腦皆可使用

## 在自己的電腦啟動

需要先安裝 Node.js 18 或更新版本。

1. 解壓縮專案。
2. 在專案資料夾開啟終端機。
3. 安裝套件：

   ```bash
   npm install
   ```

4. 啟動網站：

   ```bash
   npm start
   ```

5. 瀏覽器開啟 `http://localhost:3000`。

## 讓不同地方的朋友也能連線

要讓朋友透過網際網路加入，必須把這個 Node.js 專案部署到公開主機。以下以 Render 為例：

1. 將整個專案資料夾上傳到自己的 GitHub repository。
2. 登入 Render，選擇 **New → Web Service**，連接該 repository。
3. 設定：
   - Runtime：Node
   - Build Command：`npm install`
   - Start Command：`npm start`
4. 部署完成後，Render 會提供一個公開網址，例如 `https://你的網站名稱.onrender.com`。
5. 把網址分享給朋友。大家打開同一個網址後，建立或輸入房號即可一起玩。

主機必須持續運作，朋友才能連線。免費主機可能會在閒置時休眠，第一次開啟可能需要等它喚醒。

## 新增或修改題目

開啟 `server.js`，找到 `QUESTION_BANK`，依照以下格式新增題目：

```js
{
  question: "你的題目？",
  options: ["選項 A", "選項 B", "選項 C", "選項 D"],
  answer: 0,
  explanation: "答案解析。"
}
```

`answer` 使用 0、1、2、3，分別代表第一到第四個選項。

## 注意事項
- 目前房間資料存在伺服器記憶體中；伺服器重啟後，進行中的房間會消失。
- 這是可部署的入門版本，尚未加入帳號系統、永久戰績或防作弊機制。
- 題目以文字問答為主，方便自行擴充題庫。
